# Felix — Professional Portfolio Website

A responsive, single-page portfolio for Khin La Pyae Won (Felix), using a light-blue and dark-blue theme.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive styling and colors
- `script.js` — mobile navigation and current year
- `assets/profile-photo.png` — portrait extracted from the supplied resume
- `Felix-La-Pyae-Won-Resume.pdf` — PDF used by the Download Resume links

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `felix-portfolio`).
2. Extract this ZIP file.
3. Upload **all files and folders inside** `felix-portfolio` to the root of the repository. Make sure `index.html` is at the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish your site. Your website address will appear in the Pages section.
